# Football Assist Analysis

## Overview
This project analyzes football player assist statistics using Python and Pandas.

The goal was to explore:
- Top assist providers
- Assist efficiency
- Player performance trends

---

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset
The dataset contains:
- Player Name
- Games Played
- Assists

---

## Key Insights
- Some players achieved high assists in fewer games.
- Assist efficiency varies between players.
- Games played does not always predict assist count.

---

## Visualizations
- Bar Charts
- Scatter Plots
- Histograms
- Correlation Heatmaps
